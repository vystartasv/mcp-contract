THE CHECKLIST

A focused contract, with nowhere for drift to hide.

01

Manifest validation

Check tool names, descriptions, bounded input schemas, required fields, duplicates, and unknown fields.

02

Transcript matching

Correlate tools/list JSON-RPC requests and responses with stable IDs and result or error shapes.

03

Deterministic diff

Review sorted added, removed, and changed tools without pretending schema equivalence is semantic.

04

Bounded report

Emit HTML-escaped diagnostics for a safe, readable failure report that stays data-only.

WORKBENCH FLOW

From fixture to evidence.

The command never starts a server. It reads a bounded file, applies the documented subset, and returns a stable answer.

  1. BuildCompile the standalone Bun binary.
  2. CheckValidate a manifest or .jsonl transcript.
  3. DiffCompare two manifests by tool definition.
  4. ReportWrite escaped HTML only when requested.

BOUNDARIES

Useful because it stops here.

Included: offline manifest checks, transcript correlation, deterministic diffs, bounded diagnostics, and escaped reports.

Explicit non-goals

No MCP server, transport, network request, URL following, tool execution, agent framework, telemetry, or general JSON Schema implementation.

Safety envelope: input ≤ 1 MiB · events ≤ 256 KiB · tools ≤ 1,000 · schema depth ≤ 12 · diagnostics ≤ 100

QUICKSTART

Run the lab locally.

Requires Bun 1.3+. These supported commands use checked-in fixtures and send no requests.

git clone https://github.com/vystartasv/mcp-contract.git
cd mcp-contract
bun install --frozen-lockfile
bun run build
./dist/mcp-contract check fixtures/valid-manifest.json
./dist/mcp-contract check fixtures/valid-transcript.jsonl
./dist/mcp-contract diff examples/manifest-a.json examples/manifest-b.json

LOCAL EVIDENCE

Expected results

  • OK valid-manifest.json
  • OK valid-transcript.jsonl
  • + / - / ~ sorted tool changes
  • 0 valid · 2 contract invalid
